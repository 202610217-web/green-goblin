# 🏰 고블린 던전 호텔

고블린 사장이 되어 던전을 호텔로 바꾸고, 모험가 손님을 받아 돈을 버는 3D 타이쿤 게임입니다.
(Three.js 사용, 모델 파일 없이 기본 도형으로만 표현)

## 진행 상황

- [x] 큰 단계 1: 3D 기본 게임 (화면 구성, 방 설치/철거, 손님과 별점)
- [ ] 큰 단계 2: 콘텐츠 확장 (층 확장, 직원, 용사 습격)
- [ ] 큰 단계 3: 회원 시스템과 마무리 (Neon DB, 로그인, 저장)

## 내 컴퓨터에서 실행하기

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 실행되지 않습니다. 간단한 웹 서버로 열어주세요.

```bash
# 방법 1: Node.js가 있으면
npx serve public

# 방법 2: Python이 있으면
cd public
python3 -m http.server 8000
```

그다음 브라우저에서 표시된 주소(예: http://localhost:3000 또는 http://localhost:8000)를 엽니다.
Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작법

| 조작 | 설명 |
| --- | --- |
| 건설 메뉴 클릭 / 숫자키 1~5 | 방 종류 선택 |
| 빈 칸 클릭 | 선택한 방 설치 |
| 설치된 방 클릭 | 철거 (비용 절반 환불) |
| 마우스 드래그 | 시점 회전 |
| 마우스 휠 | 확대 / 축소 |
| 오른쪽 드래그 | 화면 이동 |
| 스페이스바 | 일시정지 |

## 파일 구성

```
public/
  index.html   화면 뼈대 (UI 요소, Three.js 불러오기)
  style.css    UI 스타일
  config.js    ★ 가격·수익·시간 등 모든 설정값
  state.js     게임 진행 데이터(gameState) — 나중에 DB에 그대로 저장
  game.js      게임 규칙 + 메인 루프 (시작 파일)
  scene.js     Three.js 3D 화면 (카메라, 던전, 클릭 판정, 효과)
  models.js    기본 도형으로 만든 3D 모델 (방 5종, 고블린, 손님)
  ui.js        화면 위 HTML UI (상태바, 건설 메뉴, 손님 목록, 알림)
```

숫자를 바꾸고 싶으면 `public/config.js`만 수정하면 됩니다.
